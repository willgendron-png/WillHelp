# WillHelp

WillHelp is a browser-local set of student support tools for nursing students. The public release is a single static page: open `index.html` in a browser or publish the repository with GitHub Pages. It has no server, account, analytics, AI service, or external runtime dependencies.

## Privacy

Information students enter is stored in browser storage on that device. It is not sent to WillHelp or a server. Anyone using a shared device should enable Shared computer mode and clear their information when finished. Do not enter Social Security numbers, bank logins, patient information, or background check details. Clearing browser data or switching devices removes access to saved information.

## Important limitations

WillHelp is an independent resource and is not an official Simpson University service or endorsed by Simpson University unless expressly stated. Its automated suggestions are general educational and career-planning guidance, not legal advice, an official eligibility decision, or a directive from a school, employer, training provider, or government agency. Information about requirements, prices, funding, openings, deadlines, and availability may be outdated; confirm details directly with the responsible organization before relying on them. WillHelp is not an emergency service and is not monitored. In an emergency, call 911; for a mental health crisis in the United States, call or text 988.

Sources and provider links are included in the app. Follow those links to confirm current information.
